# Rifa Navideña 2026 - dtc & co

Página web estática moderna diseñada para la **Rifa Navideña 2026** de Monte Plata, lista para alojarse directamente en **GitHub Pages**.

## Características del Diseño
- **Fidelidad al Folleto / Afiche:**
  - Paleta de colores terracota cálido, verde salvia y arena/crema.
  - Tarjetas de exhibición de vehículos: *1er Lugar: Honda CR-V Touring 2022* y *2do Lugar: Supermoto Husqvarna 701 (2026)*.
  - Marco conmemorativo para el *3er Lugar (10 Premios de RD$10,000)* y el llamado de compra de boletos a RD$300.
  - Insignia de fecha y ubicación (*20 de Diciembre | Monte Plata*) y advertencia de tarifa final (*RD$500*).
  - Identidad gráfica *dtc & co* y líneas directas telefónicas y de WhatsApp (*849-243-7510* y *646-668-7510*).
- **Sobriedad y Elegancia:**
  - Diseño serio y profesional sin emojis informales.
  - Íconos vectoriales SVG limpios y nítidos en todas las resoluciones.
  - Tipografía moderna (*Outfit* y *Plus Jakarta Sans*).
- **Herramientas de Conversión para Rifas:**
  - Cronómetro de cuenta regresiva hacia el día del sorteo.
  - Barra de estado de emisión de boletos disponibles.
  - Selector dinámico de paquetes (1, 3, 5, 10 o cantidad personalizada).
  - Generador de folios preasignados.
  - Botón directo de reserva que genera un mensaje formal preformateado en WhatsApp.
  - Especificaciones técnicas de cada vehículo y procedimiento en 3 pasos.
  - Preguntas frecuentes y ventana modal con las Bases del Sorteo.
  - Barra fija inferior en móviles para alta tasa de conversión.

## Cómo Publicar en GitHub Pages

1. **Subir los cambios a tu repositorio en GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Boceto oficial Rifa Navideña 2026"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
   git push -u origin main
   ```

2. **Activar GitHub Pages:**
   - Entra en tu repositorio en GitHub.
   - Ve a **Settings** > **Pages** (en el menú lateral izquierdo).
   - En **Build and deployment** > **Source**, selecciona `Deploy from a branch`.
   - En **Branch**, selecciona `main` y la carpeta `/(root)`.
   - Haz clic en **Save**. En un par de minutos tu página estará activa en:
     `https://TU-USUARIO.github.io/TU-REPOSITORIO/`
